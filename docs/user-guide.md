# Rift Draft 사용 가이드

Rift Draft는 리그 오브 레전드 밴픽 단계에서 **다음 픽 후보**와 **아이템 초안**을 보여주는 도우미입니다. 지금 입력된 아군·상대 조합과 내 챔피언 풀·숙련도를 함께 보고 후보를 고릅니다.

- 추천 점수는 **조합 적합 점수**이며 승률이 아닙니다.
- 챔피언 주석과 아이템 템플릿은 편집 규칙으로 만든 초안입니다. 판단은 직접 하시고, 이 도구는 참고로만 쓰세요.
- Riot Games의 공식 도구가 아니며 Riot Games의 보증을 받지 않았습니다.

---

## 1. 어떤 방식으로 쓸까

| | 웹 데모 | 로컬 실행판 |
|---|---|---|
| 여는 방법 | 배포된 주소를 브라우저로 열기 | 내 PC에서 `npm start` 후 `http://127.0.0.1:4173` |
| 밴픽 추천·아이템 초안·온톨로지 | ✅ | ✅ |
| 챔피언 스킬 정보 | ✅ | ✅ |
| 롤 클라이언트 자동 연동 | ❌ | ✅ |
| OP.GG 통계·상성 | ❌ | ✅ |
| 최신 패치 데이터 | 배포 시점 기준 (매주 갱신) | 실행 중 자동 확인 (6시간마다) |

**구경만 하려면** 웹 데모로 충분합니다. **실제 게임에서 쓰려면** 로컬 실행판을 권장합니다.

### 로컬 실행판 설치

1. [Node.js](https://nodejs.org/) 20.11 이상을 설치합니다.
2. 저장소를 내려받고 실행합니다.
   ```sh
   git clone <저장소 주소>
   cd lolontology
   npm start
   ```
   실행에 필요한 추가 패키지는 없어서 `npm install` 없이 바로 됩니다.
3. 브라우저에서 `http://127.0.0.1:4173`을 엽니다.

처음 실행하면 Riot Data Dragon에서 최신 챔피언·아이템 데이터를 받아 PC에 저장합니다. 상단 데이터 표시줄이 **공식 정적 데이터 · 챔피언 16.xx · 아이템 16.xx**로 바뀌면 준비가 끝난 것입니다.

## 2. 처음 한 번만: 내 챔피언 풀 설정

추천의 질은 내 풀 정보에 크게 좌우됩니다. 게임 전에 미리 해 두세요.

1. **밴픽** 탭으로 갑니다.
2. **다음 픽 후보** 영역에서 **내 챔피언 풀 N명 · 편집**을 누릅니다.
3. 검색창에 한글이나 영문 이름을 입력해 챔피언을 추가합니다.
4. 추가한 챔피언마다 아래 항목을 고릅니다.

| 항목 | 선택지 | 추천에 주는 영향 |
|---|---|---|
| 선호도 | 보통 / 선호 / 최선호 | 0 / +5 / +10점 |
| 숙련도 | 연습 중 / 기본 가능 / 익숙함 / 주력 | −10 / 0 / +12 / +24점 |
| 플레이 역할 | 탑·정글·미드·바텀·서포터 체크 | 체크하면 **그 역할에서만** 후보로 나옵니다 |

- **풀 안에서만**을 체크하면 내 풀에 있는 챔피언만 후보로 나옵니다.
- 숙련도를 비워 두면 "숙련도 미입력"으로 표시되고 점수에 반영되지 않습니다.
- 풀과 설정은 이 브라우저에만 저장되고, 다음에 열어도 그대로 남아 있습니다.

## 3. 게임 중 사용: 밴픽 단계

### 방법 A. 클라이언트 연동 (로컬 실행판, 권장)

1. 롤 클라이언트를 켠 **같은 PC**에서 `npm start`로 앱을 실행합니다.
2. **밴픽** 탭에서 **클라이언트 연동**을 누릅니다. 버튼이 **연동 끄기**로 바뀝니다.
3. 큐가 잡혀 밴픽 화면에 들어가면 **2초마다** 아래 항목이 자동으로 채워집니다.
   - 내 역할 (배정된 포지션)
   - 아군 픽, 상대 픽
   - 양 팀 밴
4. 버튼 아래 상태줄에 진행 상황이 나옵니다.
   - `밴픽 연동 중 · 내 픽 차례 · 선택 중: 오리아나 · 상대 포지션은 추정`
   - `클라이언트 연결됨 · 밴픽 화면을 기다리는 중`: 아직 밴픽 전입니다.
   - `클라이언트 대기 · 롤 클라이언트가 실행 중이 아닙니다`: 아래 문제 해결을 보세요.

알아둘 점:
- 연동은 **읽기 전용**입니다. 픽이나 밴을 대신 하지 않습니다.
- 소환사 이름·계정 정보는 화면으로 넘어오지 않습니다. 챔피언과 포지션만 사용합니다.
- 랭크 게임에서는 클라이언트가 **상대 포지션을 알려주지 않습니다**. 그래서 각 챔피언의 주 포지션으로 추정해 배치합니다. 틀렸다면 슬롯을 눌러 직접 옮기세요.
- 손으로 고친 내용은 밴픽 상황이 다시 바뀔 때까지 유지됩니다.

### 방법 B. 직접 입력 (웹 데모·로컬 공통)

1. 상단 **내 역할** 탭에서 내 포지션을 고릅니다.
2. **현재 밴·픽** 보드에서 슬롯을 눌러 챔피언을 고릅니다.
   - 아군·상대 슬롯은 **포지션 순서**(탑·정글·미드·바텀·서포터)입니다. 상대도 가능하면 맞는 포지션 칸에 넣으세요. 같은 챔피언도 포지션에 따라 다르게 평가합니다.
   - 슬롯을 비우려면 선택 창에서 **이 슬롯 비우기**를 누릅니다.
3. **예시 조합**으로 동작을 미리 볼 수 있고, **초기화**는 밴·픽만 지웁니다. 풀과 설정은 유지됩니다.

### 후보 카드 읽는 법

**다음 픽 후보**에는 상위 3명이 카드로 나옵니다.

- **적합 점수**: 아래 근거를 더한 값입니다.
  - 역할 프로필이 있는 후보: +30
  - 내 풀에 포함: +5
  - 선호도와 숙련도: 위 표 참고
  - 아군 조합에 없는 특성을 채워 줌: 전방 유지 +12, 교전 시작 +10, 아군 보호 +7, 웨이브 정리 +6
  - 물리 위주 아군에 마법 피해, 또는 그 반대: +12
  - 상대 진입이 많을 때 아군 보호 수단: +9
  - 상대 전방이 두꺼울 때 지속 피해 후보: +8
  - 같은 라인 상대가 입력됐을 때 맞라인 성향: −8 ~ +8. 전방 유지·교전 시작 특성, 사거리 견제, 마법 대 물리 피해를 비교합니다. 실제 상성 데이터로 점검한 결과는 [실제 데이터 점검 보고서](real-data-report.md)에 있습니다.
- **근거와 한계**를 펼치면 항목별 점수, 주석의 검토 상태("검토 전 초안 주석" 등), 주의할 점을 볼 수 있습니다.
- 아군·상대가 덜 채워졌을수록 순위가 바뀔 수 있습니다.
- **이 픽 선택 →**을 누르면 내 슬롯에 넣고 아이템 페이지로 이동합니다.

### OP.GG 상성 보기 (로컬 실행판)

후보 영역 위의 **OP.GG 상성 보기**를 누르면 상위 후보 3명을 차례로 조회해 카드에 붙여 줍니다. 3명이라 몇 초 걸립니다.

- 전체 승률과 게임 수
- 강한 상대·약한 상대 상위 3명과 그 상대로의 내 승률
- 지금 **상대 팀에 있는 챔피언**이 목록에 있으면 강조 표시

OP.GG가 상성을 3명씩만 주기 때문에, 내 라인 상대가 목록에 없는 경우가 많습니다. 이 통계는 **점수에 넣지 않는 참고 정보**입니다. 지역·패치 범위도 응답에서 확인되지 않습니다.

## 4. 아이템 페이지

내 역할 슬롯에 챔피언이 들어가면 **아이템** 탭에 초안이 만들어집니다.

- **첫 아이템**: 라인 시작용입니다. 서포터는 서포터 아이템으로 시작합니다.
- **코어 아이템**: 최종 6칸 중 신발을 뺀 5개입니다. 원딜은 신발을 판 뒤 6코어 예시를 보여줍니다.
- **신발**: 상대 피해가 한쪽에 몰리면 방어 신발로 바뀝니다.
- **상황별 대안**: 상대가 회복·마법 피해·탱커에 치우치면 교체 후보가 나옵니다. 근거에 어떤 상대 때문인지 경로가 표시됩니다.
- 빌드 유형은 **챔피언과 포지션 기준**입니다. 예를 들어 서포터 갈리오와 미드 갈리오는 다른 템플릿을 씁니다.

로컬 실행판에서 밴픽 탭의 **OP.GG 연결 → 챔피언 분석 · 빌드**를 조회하면, 아이템 페이지에 **OP.GG 통계 기반 아이템**과 **템플릿 비교**가 추가됩니다. 이 통계는 챔피언·포지션·아이템 패치가 지금 선택과 모두 같을 때만 표시됩니다.

## 5. 온톨로지 페이지

챔피언·아이템이 서로 어떻게 연결되는지 직접 조회하는 화면입니다.

- 이름이나 ID로 검색하고 **패치·역할·관계**로 거를 수 있습니다.
- 챔피언 카드에서 볼 수 있는 것:
  - 포지션, 피해 성향, **포지션별 차이**
  - 주석 검토 상태: 초안 주석 / 검토 전 초안 / 의미 주석 없음
- 관계 칩의 괄호 안 포지션은 **그 포지션에서만** 성립하는 관계라는 뜻입니다. 예: `효과 마법 피해 (서포터)`.
- **그래프로 보기**를 누르면 선택한 노드의 직접 관계를 그래프로 보여줍니다.

## 6. 데이터와 개인정보

- 밴픽 상태, 챔피언 풀, 선호도·숙련도는 **이 브라우저에만** 저장됩니다. 서버나 다른 곳으로 보내지 않습니다.
- 상단 **이 브라우저에 저장되는 데이터와 외부 전송**에서 전체 목록을 볼 수 있습니다. **이 브라우저의 저장 데이터 모두 삭제**로 한 번에 지울 수 있습니다.
- OP.GG에는 조회 버튼을 누를 때만 챔피언·포지션 같은 조회 조건을 보냅니다. 계정 정보는 보내지 않습니다.
- 새 패치 데이터가 필요하면 상단의 **최신 데이터 새로고침**을 누르세요.

## 7. 문제 해결

**"클라이언트 대기 · 롤 클라이언트가 실행 중이 아닙니다"가 계속 떠요**
- 롤 클라이언트와 `npm start`가 **같은 PC**에서 실행 중인지 확인하세요.
- 기본 경로가 아닌 곳에 롤을 설치했다면, 설치 폴더의 `lockfile` 위치를 지정해서 실행하세요.
  - macOS / Linux:
    ```sh
    LOL_LOCKFILE="/경로/League of Legends/lockfile" npm start
    ```
  - Windows PowerShell:
    ```powershell
    $env:LOL_LOCKFILE="D:\Games\League of Legends\lockfile"; npm start
    ```
- `lockfile`은 클라이언트가 켜져 있을 때만 생깁니다.

**상대 포지션이 틀리게 들어가요**
- 랭크 게임에서는 상대 포지션이 공개되지 않아 추정한 것입니다. 슬롯을 눌러 직접 고치세요. 다음 픽이 들어올 때 다시 추정됩니다.

**"OP.GG 연결 실패"가 떠요**
- 인터넷 연결을 확인하세요.
- OP.GG 조회는 1분에 20번까지만 됩니다. 잠시 뒤 다시 시도하세요.
- 웹 데모에서는 OP.GG를 쓸 수 없습니다.

**"예제 데이터"로 표시돼요**
- 공식 데이터를 아직 받지 못한 상태입니다. 인터넷 연결을 확인하고 **공식 데이터 다시 불러오기**를 누르세요.

**"서버를 시작할 수 없습니다"가 떠요**
- 4173 포트를 다른 프로그램이 쓰고 있을 수 있습니다. `PORT=4180 npm start`처럼 다른 포트로 실행하세요.

**추천이 이상해요**
- 아군·상대를 더 채우면 정확해집니다.
- 많은 챔피언 주석이 아직 **검토 전 초안**입니다. 잘못된 값을 발견하면 `src/champion-drafts.js`(기본값)나 `src/role-overrides.js`(포지션별 차이)를 고치거나 알려주세요.

## 8. 한계

- 점수는 편집 규칙 기반 **조합 적합도**이며 승률을 예측하지 않습니다.
- OP.GG 통계는 지역·패치 범위가 확인되지 않아 추천 점수에 넣지 않습니다.
- 아이템은 빌드 유형별 템플릿이며, 챔피언별 최적 빌드가 아닙니다.
- 챔피언 주석 중 129명과 포지션별 차이는 사람 검토 전 초안입니다.
